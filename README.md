## 🌐 Project Overview:
CareerGrid is a full-stack **Job Listing Portal** that connects **students (job seekers)** with **employers** through a secure and efficient hiring platform.
The system ensures **trusted recruitment** by allowing only admin-verified employers to post jobs.

---

## 🛠 BACKEND (Core System):
A complete backend built using **Node.js, Express.js, and MongoDB** with modular architecture.

---

### 🔐 Authentication:
* User registration & login
* Password hashing (bcrypt)
* JWT authentication
* Role-based access (Student / Employer / Admin).
  
--

### 👤 Profile Management:
* Student profile
* Employer company profile
* Resume upload
* Profile update APIs.
  
---

### 🛡️ Employer Verification (Admin Control);
* Admin approval required
* Unverified employers cannot post jobs
* Fake employer protection system.
  
---

💼 Job Listings:
* Create / update / delete jobs
* View public jobs
* Employer ownership protection
  
---

### 📄 Job Applications:
* Apply to jobs
* Prevent duplicate applications
* Track application status
* Employer can view applicants.
  
---

### 📊 Dashboards:
* Student dashboard
* Employer dashboard
* Job statistics
  
---

### 🔍 Search & Filters:
* Keyword-based search
* Location filtering
* Pagination
  
---

### 🔔 Notifications:
* Application alerts
* Notification tracking.
  
---

### 🔐 Security Features:
* JWT route protection
* Role-based authorization
* Input validation
* Duplicate prevention
